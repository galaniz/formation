# urlEncode  

**<code>urlEncode(value: object, _key?: string, _data?: string[]): string</code>**  

Recursively convert object key value pairs into url encoded string.

## Parameters  
- **`value`** <code>object</code> required  
- **`_key`** <code>string</code> optional  
- **`_data`** <code>string[]</code> optional

## Returns  

<code>string</code>
